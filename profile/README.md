# JFC-MIT

**Just Furnish Context (JFC)** — an MIT-led research collaboration demonstrating that AI agents can autonomously execute high energy physics analyses end-to-end, from event selection and systematic uncertainty evaluation to statistical inference and paper drafting.

## Our Work

We have demonstrated that large language model-based AI agents can autonomously perform experimental HEP analysis pipelines across three experiments:

| Experiment | Analyses |
|---|---|
| **ALEPH** | Z-Boson Lineshape, Lund Jet Plane, EEC Correlators, R_b/R_c & A_FB |
| **DELPHI** | N_ν from Γ_inv, Lund Jet Plane, Hadronic Event Shapes, Jet Substructure |
| **CMS** | H → ττ |
